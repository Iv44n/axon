# Decisions (ADR)

One leaf per decision, in the branch of its topic; the number is global and never reused. A decision changes through a new
ADR (a statement the code made false is corrected where it stands). A new ADR goes in the branch it belongs to; none fits: a new branch.

- [Core](core/INDEX.md) — 0001-0013, 0039, 0041: stack, rendering, data-oriented rules, own implementations, Wayland client, Windows port, the lock.
- [Interface](interface/INDEX.md) — 0012-0022, 0036-0037: glass look, config and settings file, prompt chips, text quality, i18n, the reference cleaner, the docked prompt.
- [Workspace](workspace/INDEX.md) — 0023-0034, 0038: windows, panes, overlays, palette, overview, groups, drag, fidelity, a scope per window.
- [Distribution](distribution/INDEX.md) — 0035, 0040: release bundles, the `curl | sh` and `irm | iex` installers, the website on GitHub Pages.
